# 英语开口练习 — LearnHarness 插件

[English](./README.md)

把自己想说的话，从母语变成能脱口而出的外语。贴一小段话，插件把它翻译成你在学的语言、合成原声，然后带你听、分段跟读、完整跟读、试背。说得出来的句子进入间隔复习：卡片只显示母语的意思，你要在几秒内开口。

默认是中文到英语，这也是它最初的用途。母语和学习语言都可以改成 [33 种语言](#语言)里的任意一种。

这是 LearnHarness 的社区插件（`apiVersion: 1`，id `speak-english`，`minAppVersion 0.7.0`）。界面有中文和英文两种。

## 方法

插件照着李笑来《1000 小时》的流程做：用母语写下想说的话，转成要学的语言和语音，跟读，背诵，复习。它改了其中两处，并加了时限：

1. **练自己的句子。** 内容不来自教材，是你在组会或闲聊里真要说的话，场景可选正式或口语。
2. **线索是意思，不是上一句。** 整段背诵练的是「第 2 句带出第 3 句」。这里的卡片给母语的意思、要你说出那句话，和真实对话里的线索一致。只有这个方向进入排期。
3. **每句按自己的遗忘进度排期。** 复习用 FSRS-6，目标保持率 95%，有每日上限，不是「周日复习一周」。
4. **开口有时限。** 连接存在但太慢，在对话里用不上。复习卡给你读完题目的时间，再加几秒思考；来不及开口就算没说出来。没说出来的卡 10 分钟后再来。
5. **你来判定，分数只供参考。** 两个按钮：「说出来了」或「没说出来」。发音评分在后台算，逐词标记，但不影响排期。
6. **总说不出来的句子，先分清缺什么，再讲解。** 先不限时再说一遍。能说出来，缺的只是速度，不讲解。说不出来，再请模型讲这句难在哪里，并给出更简单的说法或拆成两句的方案，你可以采用来替换原句。

完整的设计、每条规则的理由和决定记录在 [`docs/plan.md`](./docs/plan.md)。

## 需要自备

| 用途 | 服务 | 在哪里填 |
| --- | --- | --- |
| 翻译、讲解、问句 | LearnHarness 里配置的模型（默认用 cheap 档） | 应用设置，或本插件设置里另选 |
| 给段落上课（可选） | LearnHarness 上课用的模型（strong 档） | 应用设置 |
| 原声 | ElevenLabs 密钥 | 本插件的设置页 |
| 发音评分 | Azure 语音密钥和区域 | 本插件的设置页 |

三者都是你自己的账号，都可能产生费用。插件只把各自需要的内容发过去：你写的原文发给模型，讲解时再加上这句话和你的练习次数；译出的句子发给 ElevenLabs；一句话的录音（最长 30 秒）和它的参考文本发给 Azure。把段落交给老师时，句子、母语意思和摸底结果发给 LearnHarness 上课用的模型。

其余都留在本机的插件数据目录里：段落和练习记录、原声、每段第一次和最近一次的完整跟读录音，以及两把密钥（`secrets.json`，仅本人可读，保存后界面不再显示）。摸底、分段跟读、试背和复习时的录音评分后就丢弃。

## 语言

两项设置决定新段落从什么语言翻译成什么语言：**母语**和**学习语言**。默认是中文（普通话，简体）和英语（美国）。第一次打开插件时，首页会请你确认或修改；之后可以在设置页或「新段落」页面顶部改。把一边选成另一边已有的语言时，两者对调。

每个段落记住自己建立时的语言。改设置只影响之后新建的段落，所以一次复习里可以有不同语言的卡片，每张卡片都写明要说哪种语言。

可选的是 Azure 发音评估支持的 33 个语言和地区：阿拉伯语（埃及、沙特阿拉伯）、粤语、加泰罗尼亚语、中文（普通话简体、台湾繁体）、丹麦语、荷兰语、英语（澳大利亚、加拿大、印度、英国、美国）、芬兰语、法语（加拿大、法国）、德语、印地语、意大利语、日语、韩语、马来语、挪威语、波兰语、葡萄牙语（巴西、葡萄牙）、俄语、西班牙语（墨西哥、西班牙）、瑞典语、泰米尔语、泰语和越南语。默认的语音模型 `eleven_v4` 能说全部这些语言；列表里较旧的模型支持的语言少一些。

各语言的差别：

- **评分。** 韵律分和「听起来像」的提示只有美式英语有。普通话会指出不清楚的音节（如 `qi 4`）。其他语言有准确度、流利度、完整度，以及每个词读对、读得不准、漏读还是多读。
- **不分词的文字**（中文、粤语、日语、泰语）。逐词标记按评分服务的分词显示；按词数的规则改按字数。
- **提示词。** 学美式英语时，翻译用书里的两个角色提示词。其他语言用同样的文字，填入语言名。讲解用你的母语写。
- **读题速度。** 中文、粤语、日语、韩语、泰语的题目按每秒字数算，其他语言按每秒词数算。
- **声音。** 默认的两个声音是英语声音。用 `eleven_v4` 时，把 Jessica 说的 33 种语言送去评分，发音总分在 84 到 100 之间，所以都能用；想要母语者的声音，可以在设置里换成别的 ElevenLabs 声音 ID。

## 安装

### 下载发布包（不需要构建工具）

需要：LearnHarness 0.7.0 或更高版本。

1. 从[最新发布](https://github.com/wangdepin/speak-english-plugin/releases/latest)下载 `speak-english-<版本>.zip`。
2. 在 LearnHarness 里打开 **Settings → Community plugins**，找到插件目录。
3. 把压缩包解压到这个目录。压缩包里是 `speak-english/dist/`，解压后应该有 `<插件目录>/speak-english/dist/manifest.json`。
4. 刷新 Community plugins，启用「英语开口练习」，再到插件设置里填两把密钥和 Azure 区域。同一页的「测试麦克风和评分」可以一次检查麦克风、密钥和区域。

更新时删掉 `speak-english/dist/`，把新的发布包解压到原处。不要删 `speak-english/data/`：里面是你的段落、练习记录、密钥和音频。然后重启 LearnHarness。

0.1.0 写下的数据会在新版本第一次启动时转换，旧文件保留在旁边，名为 `data/store.v1.json`。

### 从源码构建

需要：LearnHarness 0.7.0 或更高版本，较新的 Node.js 和 npm。

```sh
git clone https://github.com/wangdepin/speak-english-plugin.git
cd speak-english-plugin
npm ci
npm run install:local -- "<数据目录>"
```

`<数据目录>` 是应用的数据目录；macOS 桌面版是 `~/Library/Application Support/MasteryHarness/data`。这条命令先构建，再装到 `<数据目录>/plugins/speak-english/dist/`：

```text
speak-english/
  dist/
    manifest.json
    main.js           # 浏览器端 ES 模块
    backend.cjs       # Node CommonJS
    styles.css
    LICENSE
    FSRS-LICENSE.txt
  data/               # 你的段落、密钥和音频，不随插件分发
```

然后按上面第 4 步启用插件并填密钥。

更新时再跑一次 `npm run install:local`，然后重启 LearnHarness。安装只替换 `dist/`，不碰旁边的 `data/`。

`npm run package` 会在 `release/` 里生成发布包和它的 SHA-256 校验和。

## 流程

插件在侧边栏加一个「开口练习」入口（英文界面叫 Speak English）。它不读你的课程；只有从这里的段落开的课，课堂才会用到它。

1. **录入。** 用母语写一小段话（100 到 150 字，或 60 到 100 词），选正式或口语，翻译。译文只需整段确认一次，每句的意思、句子和关键说法都可以改。保存后合成原声。
2. **听。** 整段或单句，原速或放慢。
3. **分段跟读。** 听一句，录一句，看每个词是读对、读得不准、漏读还是多读，以及不清楚的音听起来像什么。
4. **完整跟读。** 戴着耳机跟着原声录下整段。保留第一次和最近一次的录音，方便以后对比。
5. **试背。** 看母语的意思，说出那句话。说出来的句子第二天进入复习，其余的明天再试背。
6. **复习。** 每天做到期的卡：读题目，在倒计时结束前开口，对照答案和自己的录音，然后自己判定。

**先学一遍（可选）。** 段落页在练习步骤上面有一行，用来在开练之前先把这一段学懂。做法来自泡芙方《20 天突破英语听力》的听力方法：找出听不出来的地方，确认每个词都懂，然后朗读和变速听。三个入口可以单独用，也可以跳过。

- **摸底。** 先不看文本听整段一遍。然后逐句：听，凭记忆复述，再看原文。没说出来的词划掉，说得不清楚的词标出，不认识的词自己点出来。
- **交给老师。** 插件在 LearnHarness 里新开一节课讲这一段。老师拿到句子、母语意思和你的缺口，先抽查几处再讲：不认识的词给意思和例句；没听出来的地方当作一整块声音来讲，不讲连读、弱读规则，你问了才讲。这需要 LearnHarness 的版本支持插件扩展课堂代理。开课用到 LearnHarness 插件接口之外的两处（`POST /api/chats` 和 `sessionStorage` 里的开场消息），LearnHarness 升级后这个按钮可能失效，别的功能不受影响。
- **朗读和变速听。** 朗读三遍，然后按 1 → 1.5 → 2 → 3 → 2 → 1.5 → 1 倍听整段，可以选每个速度听三遍。

另有两个不排期的可选练习：

- **只听一遍。** 每句只放一遍，没有文字，可以加快到 1.2 倍。没听懂的句子，看到文字后再分：一看就懂是缺声音这一端，看了还是不懂是缺配对。
- **接话。** 针对你背过的段落问一个问题，换一个声音，只问一遍，你用背过的话回答。问句由模型建议，你确认后才保存。

## 快捷键

各练习页面用同一套键，页面底部有一行列出当前能用的键。

| 键 | 作用 |
| --- | --- |
| 空格 | 开始 / 结束录音 |
| `↓`、`→` 或 Enter | 下一句、继续、开始 |
| `↑` 或 `←` | 上一句（分段跟读） |
| `R` | 播放原声，再按一次停止 |
| `M` | 播放我的录音 |
| `S` | 慢速播放（只听一遍） |
| `1` | 否定的判定：没说出来、没听懂、没接上 |
| `2` | 肯定的判定：说出来了、听懂了、接上了 |
| `A` | 想不起来，看答案 |
| `E` | 讲解 |

删除、采用新说法和返回特意不给快捷键。在输入框里打字或有对话框打开时，快捷键不起作用。

## 设置

| 设置 | 默认 | 含义 |
| --- | --- | --- |
| 界面语言 | 中文 | 中文或 English |
| 母语、学习语言 | 中文（普通话，简体）、英语（美国） | 新段落在这两种语言之间翻译，见[语言](#语言) |
| 语音模型、声音 | `eleven_v4`、Jessica | 合成原声用的 ElevenLabs 模型和声音 |
| 问句的声音 | Eric | 「接话」练习里提问的声音 |
| 每日复习上限 | 50 | 每天复习的次数，重试也算 |
| 目标保持率 | 95% | FSRS 的目标；越高间隔越短 |
| 读题速度、思考时间 | 每秒 5 个字或 3 个词、3 秒 | 开始时限 = 题目的长度 ÷ 读题速度 + 思考时间。换母语时读题速度恢复默认值 |
| 说话时限 | 2 倍 | 说一句话的时间，按原声时长的倍数算 |
| 几次没说出来后提示讲解 | 3 | 从上次讲解之后算起 |
| 模型 | 跟随 cheap 档 | 翻译、讲解和问句用的模型 |

## 开发

```sh
npm test            # 离线测试
npm run check       # 所有源文件的语法检查
npm run build       # 产出 dist/
```

运行时没有依赖，开发依赖只有 esbuild。测试重放从真实服务录下的返回，不需要密钥，也不联网。

界面文字在代码里写中文并包在 `t('…')` 里，英文写进 `src/frontend/en.js` 或 `src/backend/messages-en.cjs`，键就是那句中文。模块顶层的常量用 `mark('…')` 标记，显示时再翻译。漏了英文、占位符对不上或者有中文没包起来，`npm test` 会报。

下面的脚本会调用真实服务，花一点额度。界面走查用无界面的 Chrome 操作一个临时的 LearnHarness 实例，拿一个 WAV 文件当麦克风；其中五个会删掉实例里的全部段落，只能对着临时数据目录跑。`language-check.mjs` 每种语言合成一句再评分，并写出语言走查要用的录音。「先学一遍」的走查还需要实例里配置了上课用的模型。

```sh
node scripts/live-check.mjs <含 SPEECH_KEY/SPEECH_REGION 的 .env> <含 ELEVENLABS_API_KEY 的 auth.json>
node scripts/ui-walkthrough.mjs <learnharness 仓库> <应用地址> <假麦克风 WAV> <截图目录>
node scripts/ui-walkthrough-practice.mjs  <仓库> <应用地址> <假麦克风 WAV> <截图目录> <.env> <auth.json>
node scripts/ui-walkthrough-review.mjs    <仓库> <应用地址> <假麦克风 WAV> <截图目录> <.env> <auth.json> <临时数据目录>

node scripts/ui-walkthrough-keys.mjs      <仓库> <应用地址> <假麦克风 WAV> <截图目录> <.env> <auth.json> <临时数据目录>
```
